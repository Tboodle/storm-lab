# Projects

## Project 1: Fetching historal HRRR data from NOAA

### Goal: Explore historal HRRR data

Download an HRRR forecast for a specified date and:

- plot temperature
- plot wind
- calculate CAPE
- calculate dewpoint
- plot precipitation
